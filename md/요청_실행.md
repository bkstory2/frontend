요청_실행.md

1. 데이터 구조 분석
- 각 행: API_CALL_CD, ACCS_URL_PATH, HTTP_STACD_VAL, callcnt, duration, lon, lat

2. 시각화 조건
- 색상: 200 성공(초록), 200 이외 실패(빨강)
- 굵기: callcnt 값 10단계로 선 두께
- 애니메이션 속도: duration 값 10단계로 effect.speed

3. 화면 구성 계획
- API(/api/data)에서 데이터 받아오기
- 각 항목을 lines3D route로 변환
- 좌표는 데이터 lon, lat 사용
- 선의 색상, 굵기, 속도 동적 결정
- 성공/실패, 호출 빈도, 응답시간 시각적 차이 극대화

4. 구현 예시 (ControlCenterDashboard.vue)
- 데이터 fetch 후 변환:
  - getLineWidth(callcnt): 1~10단계
  - getLineColor(status): 200 초록, else 빨강
  - getLineSpeed(duration): 1~10단계
  - routes = data.map(d => ({
      coords: [[d.lon, d.lat], [서울_lon, 서울_lat]],
      lineStyle: { color, width },
      effect: { speed }
    }))

5. 추가 고려사항
- 화면 전역 분포, bidirectional, 시각적 차이 극대화
